# docs/sample — 기업 제공 실적 데이터 설명

이 폴더의 `.xls` 파일 20개는 새한프라텍이 제공한 **2021~2025년 생산실적·판매실적 이력**이다.
정의서가 기대한 "기존 Claude 데모 코드"나 "ERP 재고 스냅샷"은 **포함되어 있지 않다**.
원본 파일은 거래선·운송기사 이름이 들어 있어 git에 올리지 않는다(`.gitignore`).

## 1. 파일 형식

- 확장자는 `.xls`지만 실제로는 **CP949(EUC-KR) 인코딩의 탭 구분 텍스트(TSV)** 다. 엑셀 바이너리가 아니므로 `iconv -f CP949` 또는 Node `TextDecoder("euc-kr")`로 읽는다.
- 첫 줄이 헤더, **마지막 줄은 "합 계" 합계 행**이다. 적재 시 첫 컬럼이 날짜가 아닌 행은 버린다.
- 값 뒤에 공백이 많이 붙어 있다(예: `원터치 49G [CL]` 뒤에 공백 25칸). 반드시 trim한다.
- 생산실적은 부서(1211 PET 1팀, 1212 PE 팀, 1219 PET 2팀)별로 연 1파일, 판매실적은 연 1파일이다.

| 연도 | 생산 1211 | 생산 1212 | 생산 1219 | 판매 |
| --- | ---: | ---: | ---: | ---: |
| 2021 | 5,702 | 3,041 | 9,023 | 11,566 |
| 2022 | 5,281 | 2,766 | 8,911 | 10,695 |
| 2023 | 5,891 | 2,887 | 9,240 | 10,593 |
| 2024 | 3,836 | 1,556 | 10,039 | 9,285 |
| 2025 | 5,908 | 590 | 10,074 | 19,627 |

(행 수, 헤더·합계 제외. 1212 PE팀은 2024년 9월 이후 급감.)

## 3. 품목 코드 체계 (관찰 기반, 기업 확인 필요)

| 접두 | 2025 판매 품번 수 | 생산 품번에 있음 | 추정 |
| --- | ---: | --- | --- |
| TM, TR | 298 | 예 (5년 321개) | 자사 생산 PET 용기 (TM 완제품, TR 재가공 추정) |
| FM | 19 | 예 (24개) | 프리폼(소주 52.5G, 원터치 49G 등). 2025 생산량 1~5위 |
| EM, EY, TY | 48 | EM만 | 미확인 |
| AM | 302 | 아니오 | 캡·라벨·필름 등 매입 부자재 (용량 0, 포장단위가 규격 숫자) |
| WM | 12 | 아니오 | 폐원료·공병 |

- 5년 전체: 생산 품번 913개, 판매 품번 1,333개, 거래선 342곳.
- 2025년: 생산 품번 358개(1211: 187, 1212: 13, 1219: 167), 판매 품번 680개, 거래선 216곳. 판매 품번 중 323개가 같은 해 생산 품번과 겹친다.
- 영업사원이 조회할 "출고 가능 재고"의 대상은 **TM/TR/FM 등 자사 생산품**이다. AM/WM은 시드에서 제외한다.

## 4. 정의서 5.1 품목 재고와의 대응

| 정의서 항목 | 이 데이터에서 | 비고 |
| --- | --- | --- |
| 품목코드 | 생산품번 / 품 번 | 그대로 사용 |
| 품목명·규격 | 품명/규격 (한 문자열) | 품목명과 규격을 나누지 않고 한 컬럼으로 저장, 검색은 부분 일치·공백 제거 |
| 사업장/창고 | **없음** (투입공정 "121A 제품창고"만) | 음성/청주는 임의 배분 |
| ERP 재고 수량 | **없음** | 임의 생성 |
| 단위 | 포장단위·포장단위수량 | 낱개 기준 수량 + 포장단위 표시 |
| 기준 시각 | 없음 | 시드 시각 |

## 5. 시드 활용 방침 (1단계)

- 2025년 생산·판매에 모두 등장하는 자사 생산품(TM/TR/FM) 중 생산량 상위 **약 40개**를 품목 마스터로 뽑는다.
- 거래선 상위 30곳을 상담 메모 고객명 자동완성용으로 넣는다.
- 재고 수량·사업장·변동·생산 계획은 **"참고용 임의 데이터"** 로 생성한다. 시드 파일 머리말과 화면(시드 데이터일 때 표시되는 안내 문구)에 그 사실을 적는다.
- 실적 이력 자체(5년치 행)는 1단계 DB에 넣지 않는다. 나중에 필요하면 별도 테이블로 적재한다.
