## 3. 샘플 데이터 분석 요약

자세한 내용은 `docs/sample/README.md`.

- 받은 것: 2021~2025 생산실적(3부서) + 판매실적, CP949 탭 구분 텍스트 20개 파일. 마지막 줄 합계 행, 값 뒤 공백 주의.
- **받지 못한 것**: 기존 Claude 데모 코드, ERP 재고 스냅샷(현재 수량), 사업장 구분, 변동 보정 엑셀, 생산 계획 엑셀. 따라서 **ERP의 실제 재고 컬럼·갱신 방식·사업장 구분 여부는 데이터로 확인할 수 없고 기업 회신(Q1, Q2, Q4, Q11)이 필요**하다.
- 데이터에서 확정할 수 있는 것: 품목 키는 품번(`TM00329`), 품명과 규격은 한 문자열, 단위는 포장단위+포장단위수량, 거래선 목록(342곳).
- 시드 방침: 자사 생산품(TM/TR/FM) 상위 약 40개를 품목 마스터로, 거래선 30곳을 고객명 자동완성으로 쓴다. 재고 수량·사업장·변동·계획은 "참고용 임의 데이터"로 표기해 생성한다.

## 5. 기술 스택 변경이 원안과 다른 점
